How a scan runs
Each launch creates a uniquely keyed SonarQube project so history is never overwritten.
1. Fetch + checkout the selected branch locally
2. sonar-scanner begin — register project key
3. Build / analyse sources
4. sonar-scanner end — publish to server
5. Pull metrics + issues back over the Web API
6. Level 1 AI Review over those findings, then notify
