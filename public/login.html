account help
Password resets are done by an administrator.
Ask an admin to set a new password for you from Admin → User Management. If no admin can sign in, stop the agent, delete data/users.json and restart — a fresh admin account is created and its password printed to the server console.
Can't get in?
• Accounts are local to this agent — your GitHub or BusinessNext credentials will not work here.
• After 8 failed attempts the agent blocks that address for 15 minutes.
• A disabled account reports the same message as a wrong password — check with an admin.
